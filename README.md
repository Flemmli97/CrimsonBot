# CrimsonBot

Discord bot for various things I need

# Install

Its recommended to use Docker for this

1. Download this repo and put it somewhere you want
2. Go to https://discord.com/developers/applications and make a new application
3. Save your bot token
4. Invite your bot to your discord with Administrator privileges
5. run `docker compose up` in this directory
6. The first run generates a config in the `data` directory. Paste your bot token in there and restart it.
